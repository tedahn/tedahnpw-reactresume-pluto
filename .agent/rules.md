# Repository maintenance rules

- Read `AGENTS.md` and the durable documents in `.project_context/` before changing this portfolio.
- Treat career-content governance as the source for chronology, approved metrics, attribution, and public-safety boundaries.
- Use React, Vite, custom CSS variables, Google Sans typography, and explicit FontAwesome imports.
- Follow the user-requested compact profile-card design: charcoal surfaces, a restrained warm accent, experience first, and two implementation walkthroughs.
- Keep navigation, keyboard focus, expandable evidence, responsive layout, and reduced-motion handling accessible.
- Keep public product-context imagery in `public/images/impact/`; do not add generated portraits.
- Keep career content and project links in `src/resumeData.json` and regenerate resume artifacts after changes.
- Preserve GitHub Pages deployment and Vite `base: './'`. Do not change domains or deployment behavior as part of visual work.
- Update `.project_context/` only for durable changes; use dated `.workflow_context/` records for implementation and validation handoffs.
- Report browser verification separately from build and source checks.
